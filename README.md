# The Haunted Repo

**The Haunted Repo** is a small Python 3 command-line choose-your-own-adventure
game. It is Hacktoberfest night, and you are a new contributor exploring a
haunted open-source repository filled with ghostly merge conflicts, a cursed CI
pipeline, and a friendly maintainer ghost.

## Play

The game uses only the Python standard library:

```bash
python adventure.py
```

Enter the number of a choice when prompted. Invalid choices are rejected
politely, `q` quits, and the game offers to play again after an ending.

For a reproducible random route, provide a seed:

```bash
python adventure.py --seed 7
```

For a specific non-interactive route, provide comma-separated one-based choices:

```bash
python adventure.py --path 1,1,1
```

## Tests

Install `pytest` if needed, then run:

```bash
python -m pytest -q
```

The story is stored as a dictionary in `adventure.py`, separate from the game
logic, so adding scenes and branches does not require changing the play loop.

Built with GitHub Copilot.

## How it was built

The game, tests and this README were generated by [GitHub Copilot CLI](https://github.com/features/copilot/cli) from one prompt, then play-tested by hand. The prompt:

> Build a small command-line 'choose your own adventure' game in Python 3 (standard library only) called 'The Haunted Repo'. Theme: it's Hacktoberfest night and the player is a new contributor exploring a haunted open-source repository (ghostly merge conflicts, a cursed CI pipeline, a friendly maintainer ghost). The story is data (a dict of scenes with text and choices, plus good/bad endings), kept separate from the game logic; numbered choices, polite handling of invalid input, `q` to quit, play again at an ending; a `--path 1,2,1` option to play a list of choices non-interactively; at least 10 scenes and 3 endings; pytest tests that check every choice points to a real scene, every scene is reachable, good and bad endings exist, and `--path` reaches an ending. Then run the tests and fix anything that fails.
